# D'Construct Website

A modern, fully responsive company website for D'Construct.

## Quick Start

### Option 1: Open Directly in Browser
Simply double-click `index.html` or right-click and select "Open with" your preferred browser.

### Option 2: Use Local Server (Recommended)

**Using Python (if installed):**
```bash
# Windows PowerShell
python -m http.server 8000

# Or use the provided script
.\start-server.ps1
```

Then open your browser and go to: `http://localhost:8000`

**Using Node.js (if installed):**
```bash
npx http-server -p 8000
```

**Using VS Code:**
1. Install the "Live Server" extension
2. Right-click on `index.html`
3. Select "Open with Live Server"

### Option 3: Use VS Code Debugger
1. Press `F5` or go to Run and Debug
2. Select "Launch Chrome - Open HTML File"
3. The browser will open automatically
